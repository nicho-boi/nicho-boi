## 🚀 Featured Projects

### [SunnyBooth]([https://github.com/nicho-boi/SunnyBooth](https://github.com/nicho-boi/SunnyBooth-Showcase))

A playful, cat-themed browser photobooth for capturing, uploading, customizing, and exporting photo strips. It includes live webcam capture, countdown controls, responsive previews, and high-resolution Canvas exports.

`Next.js` `React` `TypeScript` `Tailwind CSS` `Framer Motion` `WebRTC` `Canvas API`

### [ForenSight](https://github.com/nicho-boi/ForenSight)

An explainable image-forensics web app that analyzes probable signs of image editing or AI generation using metadata review, Error Level Analysis, noise checks, and compression indicators.

`Next.js` `TypeScript` `FastAPI` `Python` `OpenCV` `Pillow` `PostgreSQL`

### [Attack on Titan Guide Web App](https://github.com/nicho-boi/Attack-on-Titan-Guide-Web-App)

A fan-made interactive guide with character and Titan profiles, favorites, local data, and a Scout quiz, presented through a responsive themed interface.

`Flutter` `Dart` `Provider` `Shared Preferences` `Material Design`
